# 📌 Flask Homework Project — Message Storage App

Невеликий веб‑додаток на Flask, створений у межах домашнього завдання з курсу **FullStack Web Development on Python**.  
Додаток дозволяє надсилати повідомлення через форму та зберігати їх у локальному JSON‑файлі.

## 🚀 Функціонал

- Головна сторінка з логотипом та стилями  
- Форма для надсилання повідомлення (`/message`)  
- Обробка POST‑запиту та збереження даних у `storage/data.json`  
- Відображення всіх повідомлень на сторінці `/read`  
- Обробка помилки 404 через окремий шаблон  
- Підключення статичних файлів (CSS, зображення)
